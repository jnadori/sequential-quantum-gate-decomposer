## Mutation Operator Probabilities

**Point mutation (`mutate_point`, `mutate_point_guided`):**
- `0.7` — probability of picking a token that *neighbors* the current one (shares a qubit) to improve canonicalization acceptance rate; `0.3` for fully random substitution

**Block mutation (`mutate_block`):**
- `0.5` — per-gate probability of picking a neighboring token vs a fully random one within the block

**Grow mutation (`mutate_grow`):**
- `0.5` — probability the new gate neighbors the adjacent circuit position vs being fully random

**Candidate generation operator mix (fixed-D, `generate_candidates`):**

| Range | Operator |
|---|---|
| `[0, 0.25)` | GP-guided or plain point mutation |
| `[0.25, 0.35)` | Swap mutation |
| `[0.35, 0.50)` | Block regeneration |
| `[0.50, 0.70)` | Transplant (segment copy from donor to recipient) |
| `[0.70, 0.80)` | Uniform crossover |
| `[0.80, 0.85)` | Block mutation |
| `[0.85, 1.0]` | Random circuit injection |

For **mixed-D** mode (grow/shrink enabled), the mix shifts to include grow `[0.65, 0.70)`, shrink `[0.70, 0.85)`, and block `[0.85, 0.90)`.
